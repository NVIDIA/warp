warp.bvh\_query\_aabb\_tiled
============================

.. function:: warp._src.lang.bvh_query_aabb_tiled(id: uint64, low: vec3f, high: vec3f) -> BvhQueryTiled

   .. wp-builtin-tags::
      :kernel: true
      :python: false
      :differentiable: false

   Construct an axis-aligned bounding box query against a :class:`warp.Bvh` for thread-block parallel traversal.
   
   Alias for :func:`~warp.tile_bvh_query_aabb`; see that function for usage details and
   an example.
   
   :param id: The BVH identifier (must be the same for all threads in the block)
   :param low: The lower bound of the query box, in BVH space (must be the same for all threads in the block)
   :param high: The upper bound of the query box, in BVH space (must be the same for all threads in the block)
   
   :returns: A :class:`warp.BvhQueryTiled`.
   
   .. deprecated:: 1.18
       Use :func:`~warp.tile_bvh_query_aabb` instead.
