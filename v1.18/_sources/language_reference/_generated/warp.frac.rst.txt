warp.frac
=========

.. function:: warp._src.lang.frac(x: Float) -> Float

   .. wp-builtin-tags::
      :kernel: true
      :python: true
      :differentiable: false

   Retrieve the fractional part of ``x``.
   
   In other words, it discards the integer part of ``x`` and is equivalent to ``x - trunc(x)``.
