warp.vector
===========

.. function:: warp._src.lang.vector(*args: Scalar, length: int32 = ..., dtype: Scalar = ...) -> Vector[Scalar, Any]

   .. wp-builtin-tags::
      :kernel: true
      :python: false
      :differentiable: true

   Construct a vector of given length and dtype.
   
   If no arguments are given, the vector is zero-initialized.
