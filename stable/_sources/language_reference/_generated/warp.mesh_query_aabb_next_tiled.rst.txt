warp.mesh\_query\_aabb\_next\_tiled
===================================

.. currentmodule:: warp._src.lang

.. function:: mesh_query_aabb_next_tiled(query: MeshQueryAABBTiled) -> Tile[int32, tuple[int]]

   .. wp-function-tags::
      :kernel: true
      :python: false
      :differentiable: false

   Advance a thread-block parallel mesh AABB query and return the next batch of results as a tile.
   
   Alias for :func:`~warp.tile_mesh_query_aabb_next`; see that function for usage details
   and an example.
   
   :param query: A thread-block mesh AABB query.
   
   :returns: A register tile with one face index per thread. Test each index for ``>= 0``.
   
   .. deprecated:: 1.18
       Use :func:`~warp.tile_mesh_query_aabb_next` instead.
