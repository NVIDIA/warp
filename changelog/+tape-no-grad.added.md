Add `wp.no_grad()` to pause recording on the active `wp.Tape` and `wp.Tape.get_active()` to query it, so that library code can run non-differentiable work inside a tape it did not create. Tapes can now be nested: operations are recorded only on the innermost tape, and the enclosing tape resumes recording when the inner one exits. Previously, entering a tape while another was active raised an error.
