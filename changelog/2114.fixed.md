Fix saved APIC graphs crashing when loaded in a new process if kernels read mesh IDs from `wp.handle` arrays or
`wp.handle` fields in arrays of structs. Use `wp.handle` instead of `wp.uint64` for mesh IDs that need to be remapped
when loading a saved graph.

APIC now emits and reads `.wrp` format version 18. Recapture graphs saved with earlier formats.
