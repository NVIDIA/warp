Add block-Jacobi preconditioning for `warp.sparse.BsrMatrix` inputs with square blocks using
`warp.optim.linear.preconditioner(A, ptype)` with `ptype` one of `"block_jacobi_direct"`,
`"block_jacobi_sequential"`, or `"block_jacobi_tile"`. The preconditioner applies the inverse
of each symmetric positive-definite diagonal block instead of treating its scalar diagonal entries
independently, which accounts for coupling inside the block and can improve convergence.
