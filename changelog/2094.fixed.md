Fix use-after-free races on internal scratch memory when running on non-blocking CUDA streams, such as
`torch.cuda.Stream()` borrowed with `wp.stream_from_torch()`. Affected operations include
`wp.utils.array_scan()`, `wp.utils.array_sum()`, `wp.utils.array_inner()`, `wp.utils.runlength_encode()`,
`wp.utils.radix_sort_pairs()`, `wp.Bvh` and `wp.Mesh` construction, sparse matrix operations, volume
construction, and filling arrays with large values. Releasing this scratch memory also no longer waits for
work on unrelated blocking streams.
