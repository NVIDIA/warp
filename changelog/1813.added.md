**Experimental**: Add `wp.JetSpace()` and `wp.JetSpace2()`, forward-mode jet types that carry a value together with its
derivatives. Evaluating an ordinary `@wp.func` over them yields its gradient, or its gradient and dense Hessian, with no
hand-written derivatives. A space is described by the types of the inputs being differentiated, for example
`wp.JetSpace((wp.vec3, wp.vec3))` for a spring, and `seed()` or `directional()` build the jets from those inputs.
`wp.value()` returns a jet's value, or a plain float unchanged, so a function written generically over floats and jets
can branch on either. The number of derivative directions is fixed when the types are created, so these suit local
derivatives of one element rather than differentiation with respect to an unbounded number of variables. See
`warp/examples/optim/example_implicit_projection.py`.
