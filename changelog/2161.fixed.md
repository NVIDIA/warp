Fix CUDA LBVH trees that degrade on meshes mixing very different scales ([GH-2161](https://github.com/NVIDIA/warp/issues/2161)): primitives whose centroids share one Morton code are now split by their sorted position (Karras 2012) instead of a parity rule that chained them one level per primitive, and the Morton code uses every bit of the 64-bit sort key the group ids do not need (21 bits per axis without groups, 10 before).
