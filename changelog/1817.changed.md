Raise `wp.WarpDeterminismError` for deterministic kernels that Warp previously accepted but could not run safely, such as kernels that read, write, or apply ordinary atomics to an array that also receives deterministic atomic updates, and parallel CUDA backward launches that both mutate an array and accumulate its gradient. Deterministic compilation errors are no longer `wp.WarpCodegenError`; catch `wp.WarpDeterminismError` or `RuntimeError` instead.
