Add a `temp_storage` argument to `wp.utils.array_scan()` and a `wp.utils.array_scan_temp_storage_size()` query, so CUDA scans can use a caller-provided buffer instead of allocating and freeing temporary storage on every call. This makes `array_scan()` usable inside `wp.capture_if()` and `wp.capture_while()` bodies and inside CUDA graph captures that Warp did not start. Graphs loaded with `wp.capture_load()` on a CUDA device now preallocate scan storage, so saved scans in conditional bodies also replay. The size query accepts Python `int` and `float` as aliases for `wp.int32` and `wp.float32`.
