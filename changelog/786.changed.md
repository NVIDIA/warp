**Breaking:** Raise specific exception types instead of `RuntimeError` from the argument checks in
`warp/_src/builtins.py`. Type mismatches and unsupported dtypes now raise `TypeError`, invalid shapes,
lengths, counts, and values that must be compile-time constants raise `ValueError`, and an index count
that does not match an array's dimensionality or a tuple index that is out of range raises `IndexError`.
Code that catches `RuntimeError` around kernel builds or launches to handle these errors must be updated;
catching `Exception` continues to work. Errors that report a removed API or an internal codegen invariant
still raise `RuntimeError`.
