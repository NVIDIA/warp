Fix PTX files written by `wp.compile_aot_module()`, the kernel cache, and `wp.capture_load()` ending with a NUL byte,
which made `ptxas` fail with `Unexpected EOF` and text tools such as `grep` treat them as binary. Programs that read
these files into memory for `cuModuleLoadData()` must NUL-terminate the buffer, as the CUDA driver API requires.
