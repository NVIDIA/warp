Add `warp.geometry.swept_volume_mesh()`, which returns a single closed mesh tracing
an animated rigid assembly over all of its sampled poses (its motion envelope).
`swept_volume_field()` returns the underlying field, `swept_volume_bounds()`
sizes a domain that several fields can share, and `swept_volume_sdf()` evaluates
the field inside your own kernels. Inside and outside are classified with the
generalized winding number by default, which requires meshes built with
`support_winding_number=True`; `SweptVolumeSignMode` selects the alternatives. See
`warp/examples/geometry/example_swept_volume.py`.
`wp.Mesh` now exposes `support_winding_number`, reporting whether the mesh was
built with the data that winding-number queries need.
