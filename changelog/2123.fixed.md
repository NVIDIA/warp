Fix `wp.utils.array_cast()` failing with a code generation error when casting between multi-dimensional arrays that
have the same number of dimensions and element shape but different data types, which also made every later cast
between different data types in the process fail. When the data types differ, `array_cast()` now raises a
`RuntimeError` if `count` is larger than the input or output array instead of reading or writing past its end, and if
multi-dimensional arrays have different shapes.
