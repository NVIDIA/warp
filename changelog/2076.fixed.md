Fix host-side vector component access accepting a name that is not one component of that vector.
`wp.vec3(1.0, 2.0, 3.0).xy` returned the `x` component instead of raising `AttributeError`, and
`wp.vec2(1.0, 2.0).w` raised `IndexError`, which made `hasattr()` propagate it rather than return
`False`. Kernels already rejected both.
