Allow CUDA APIC ``.wrp`` graphs saved with ``capture_save(source_fallback=True)`` to replay on a different supported GPU by compiling packaged generated source on the guest. Default saving remains binary-only and omits CUDA source and source portability warnings; opting in rejects modules known to be unrebuildable from packaged source before publishing the artifact, listing all affected modules and reasons. Source fallback requires generated source that is unchanged since the module loaded and does not support modules that use ``strip_hash=True``, caller-provided CUDA include directories, LLVM-CUDA builds, or LTO-IR and fatbin link inputs such as MathDx tile operations. Python ``capture_load()`` and the new standalone C++ ``wp_apic_load_graph_ex()`` share the native resolver, which prefers compatible packaged or cached binaries and persists successful guest compilations in the companion ``_modules`` directory.
