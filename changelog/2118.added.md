Add a `projector_structure` argument to `warp.fem.project_system_matrix()` and `warp.fem.project_linear_system()`. Passing `projector_structure="block_diagonal"` projects the system matrix in place with a single kernel, using the block-diagonal structure of Dirichlet projectors such as those assembled with `assembly="nodal"`: this keeps the sparsity pattern of the system matrix, avoids temporary allocations and host synchronizations, and supports CUDA graph capture. The default, `"general"`, keeps the previous projection with general sparse matrix products, which also supports projectors with off-diagonal blocks.
