Fix `wp.autograd.gradcheck()` and `wp.autograd.jacobian_fd()` producing incorrect results
for Python functions that mutate their array inputs in place, and `wp.autograd.jacobian()`
leaving such inputs mutated after the call. A new `restore_inputs` parameter (default
`True`) snapshots Warp array inputs and restores them so every evaluation starts from the
original input values and the caller's inputs are left unchanged.
