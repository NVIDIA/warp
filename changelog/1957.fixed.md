Fix a failing `wp.capture_end()` leaving the stream permanently marked as capturing, so that no later
`wp.capture_begin()` on that stream can succeed and the process cannot use graph capture again.

`wp_cuda_graph_end_capture()` defines a `clean_up()` lambda that unwinds the capture bookkeeping — the
`g_captures` entry, the graph allocation table, and the terminating `EndCapture`. Every failure return
below that definition calls it, except the `cudaStreamEndCapture()` check itself, which returned
directly and left the outstanding graph allocations with no owner.
