Count the exact number of iterations of constant ``range()`` loops when applying ``max_unroll``. This is a breaking behavior change for stepped loops that previously slipped one iteration past the limit, such as ``range(0, 33, 2)`` with the default limit of 16: affected loops now use dynamic-loop lowering, which has documented automatic-differentiation limitations and may change gradients. Increase ``max_unroll`` to preserve unrolling where required.
