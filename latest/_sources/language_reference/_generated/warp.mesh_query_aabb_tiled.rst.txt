warp.mesh\_query\_aabb\_tiled
=============================

.. function:: warp._src.lang.mesh_query_aabb_tiled(id: uint64, low: vec3f, high: vec3f) -> MeshQueryAABBTiled

   .. wp-builtin-tags::
      :kernel: true
      :python: false
      :differentiable: false

   Construct an axis-aligned bounding box query against a :class:`warp.Mesh` for thread-block parallel traversal.
   
   Alias for :func:`~warp.tile_mesh_query_aabb`; see that function for usage details and
   an example.
   
   :param id: The mesh identifier (must be the same for all threads in the block)
   :param low: The lower bound of the query box, in the mesh's local space (must be the same for all threads in the block)
   :param high: The upper bound of the query box, in the mesh's local space (must be the same for all threads in the block)
   
   :returns: A :class:`warp.MeshQueryAABBTiled`.
   
   .. deprecated:: 1.18
       Use :func:`~warp.tile_mesh_query_aabb` instead.
