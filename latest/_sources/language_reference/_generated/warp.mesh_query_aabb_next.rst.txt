warp.mesh\_query\_aabb\_next
============================

.. function:: warp._src.lang.mesh_query_aabb_next(query: MeshQueryAABB, index: int32) -> bool

   .. wp-builtin-tags::
      :kernel: true
      :python: false
      :differentiable: false

   Advance an AABB or sphere mesh query to the next matching triangle.
   
   This function is retained for compatibility. Prefer :func:`mesh_query_next` for new code and
   query-type-independent traversal.
   
   :param query: The query to advance
   :param index: Output; receives the zero-based face index of the current result
   
   :returns: ``True`` if another matching triangle was found, otherwise ``False``.
