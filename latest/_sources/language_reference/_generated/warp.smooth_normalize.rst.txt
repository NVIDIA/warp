warp.smooth\_normalize
======================

.. function:: warp._src.lang.smooth_normalize(v: Any, delta: float = 1.0) -> Any

   .. wp-builtin-tags::
      :kernel: true
      :python: false
      :differentiable: true

   Normalize a vector using the pseudo-Huber norm.
   
   See :func:`norm_pseudo_huber`.
   
   .. math::
       \frac{v}{H^\prime(v)}
   
   :param v: The vector to normalize.
   :type v: Vector[Float, Any]
   :param delta: The threshold value.
   :type delta: float
   
   :returns: The normalized vector.
   :rtype: Vector[Float, Any]
