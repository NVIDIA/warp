warp.eig3
=========

.. function:: warp._src.lang.eig3(A: Matrix[Float, Literal[3], Literal[3]]) -> tuple[Matrix[Float, Literal[3], Literal[3]], Vector[Float, Literal[3]]]

   .. wp-builtin-tags::
      :kernel: true
      :python: true
      :differentiable: true

   Compute the eigendecomposition of a 3x3 matrix ``A``.
   
   The eigenvectors are returned as the columns of ``Q``, while the corresponding eigenvalues are returned in ``d``.
