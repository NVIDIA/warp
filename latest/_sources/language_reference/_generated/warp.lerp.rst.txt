warp.lerp

.. function:: warp._src.lang.lerp(a: Float, b: Float, t: Float) -> Float

   .. wp-builtin-tags::
      :kernel: true
      :python: true
      :differentiable: true

   Linearly interpolate two values ``a`` and ``b`` using factor ``t``, computed as ``a*(1-t) + b*t``.
